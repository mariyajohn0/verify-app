# Verify App

Verify App is a comprehensive verification platform that allows users to verify their details such as email, phone number, Aadhar, GST, PAN card, bank account details, and pincode using official government APIs. 

## Features
- **User Registration & Login**: Secure user authentication system using MongoDB to store user details.
- **Email Verification**: Verified via Nodemailer.
- **Phone Number Verification**: Verified via Twilio.
- **Aadhar Verification**: Verified via ApyHub API.
- **GST Verification**: Verified via RapidAPI.
- **PAN Card Verification**: Verified via RapidAPI.
- **Bank Account Verification**: Verified via RapidAPI.
- **Pincode Verification**: Verified via RapidAPI.
- **Responsive Frontend**: Built with Next.js and TypeScript.
- **Robust Backend**: Developed using Node.js, Express, and MongoDB.

## Tech Stack
- **Frontend**: Next.js, TypeScript
- **Backend**: Node.js, Express.js
- **Database**: MongoDB
- **APIs**: 
  - Aadhar: ApyHub
  - GST: RapidAPI
  - PAN Card: RapidAPI
  - Bank Account: RapidAPI
  - Pincode: RapidAPI
  - Email: Nodemailer
  - Phone: Twilio
